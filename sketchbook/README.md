# Mattia Galbusera — Sketchbook

A standalone flipbook with the supplied Works 2026 front cover and a matching solid red back cover and all 20 PDF pages in order.

Open `index.html` in a browser. Everything is included locally; no build or account is needed. You can also upload this folder to any static website host.

Click the cover or the arrows to turn pages. Drag a page corner, swipe on a touch screen, or use the left and right keyboard arrows. Use View Page to inspect the drawings at a larger size. Back to Cover returns to the front.

The cover color is set by `.cover` in `style.css`. The front artwork is in assets/cover.webp; the back is solid #d53130. Page images are in `assets/`; the original PDF is unchanged.

Page-turn engine: StPageFlip 2.0.7 by Nodlik, MIT license. License included under `vendor/`.
